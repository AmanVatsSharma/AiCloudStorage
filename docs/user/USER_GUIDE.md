# User Guide

## Overview
AI Cloud Storage is a secure storage workspace for teams and organizations with:
- file/folder management,
- sharing and governance controls,
- AI summarization tools,
- reliability/compliance reporting.

## Getting Started
1. Register or sign in from `/login`.
2. Open `/dashboard` for account overview.
3. Use `/files` to upload and organize files.
4. Use `/settings` to configure retention and bucket governance.

## Core Workflows

### Upload and Organize Files
1. Open `/files`.
2. Click **Upload** or drag-drop files.
3. Use **New Folder** for hierarchy.
4. Use multi-select + move/copy actions.

### Share Files
1. Select a file in `/files`.
2. Click **Share**.
3. Configure access level, expiry, and download permissions.
4. Share the generated link.

### Recover Deleted Content
1. Delete files in `/files` (soft-delete).
2. Open `/trash`.
3. Restore when needed or permanently delete based on policy.

### Use AI Summarization
1. Open `/ai-tools`.
2. Paste content into summary workbench.
3. Generate summary and review usage/cost telemetry.

## Team and Organization Management
- Teams: `/teams`
- Organizations: `/organizations`
- Organization member governance: `/organizations/<id>/members`

## Reporting and Operations
- Audit trail: `/audit`
- Compliance report: `/compliance`
- Reliability report: `/reliability`
